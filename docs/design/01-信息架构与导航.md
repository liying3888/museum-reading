## 1. 产品定位

「荣河读书」是博物馆面向读者的**阅读伴读小程序**：以博物馆书单为源头，陪伴读者**选书 → 阅读 → 记录 → 坚持**。文化机构的延伸，不是商城，不是社交平台。

依据（museum 岗答疑）：仓库无展品/exhibit 任何痕迹——「藏品×图书」内容产品无代码与需求支撑；书源=管理后台上架（la_book CRUD，现有文学/历史/科学/艺术/哲学 5 类）。

## 2. 设计概念定调：「数字书斋 · 钤印为证」（推荐案）

- **书斋**：中式书斋气质——宣纸底、墨色字、黛蓝骨架、细线框、衬线标题。安静、克制、有纸感。
- **钤印**：打卡具象为盖印章——读完一日钤一印；目标达成首页盖「今日已阅」印。成就感来自仪式感，不是连击数字。
- 推荐理由三条：①文化机构延伸的定位准确（博物馆×读书，气质同源）②打卡仪式感是差异化记忆点（伴读产品同质化重）③实现成本低（色板+字体+一枚印章图形，无纹理贴图跨端风险）。
- **备选方向**（若 lee 定稿时否）：现代极简阅读风（黑白灰+单强调色+无衬线）——干净但无记忆点，不做展开。

### 任务感与轻阅读感的呈现取向（lee 定稿决策点）

产品内核是督促伴读（30 分钟目标+连续打卡+计时），这个内核**保留**；视觉呈现取**轻阅读感**——留白足、信息密度低、仪式感做在细节（印章/衬线数字），不做进度条满屏/任务卡堆叠的研学任务感。理由：硬性任务感视觉与「书斋」气质冲突，且读书是自愿行为，轻呈现更留住非任务型用户。若 lee 倾向研学任务感（博物馆研学团场景），视觉层可切「任务卡加重」变体，概念与 IA 不变。

## 3. 底部导航（TabBar 四项，修 S1 导航断裂）

| Tab | 名称 | 图标语义（线性描边） | 承载 |
|---|---|---|---|
| 1 | **首页** | 卷轴/灯 | 今日目标钤印卡、继续阅读、本周书单 |
| 2 | **书库** | 立册 | 全部书目、分类筛选、搜索、详情入口（**新增页，解选书死锁**） |
| 3 | **书架** | 书堆 | 想读/在读/已读三段+进度管理 |
| 4 | **我的** | 印章人 | 账户、统计入口、目标设置、设置 |

- 统计页不占 Tab 位：入口两条=「我的」菜单+首页目标卡点击直达（首页已承载今日摘要，深访低频）。
- 实现注记（S3）：恢复底座组件式 tabBar（`components/tabbar/tabbar.vue` 改造四项），不新增原生 tabBar 机制；配色选中黛蓝、未选枯墨。

## 4. 页面结构树

```
TabBar
├─ 首页 pages/index/index
│   ├─ 今日目标钤印卡（点击卡 → 统计页）
│   ├─ 继续阅读卡（仅在读>0）────→ 阅读计时（带 bookId）
│   ├─ 本周书单（横滚）───────→ 书籍详情 / 书库（更多）
│   └─ 未登录：目标卡=登录引导（书单公开可看）
├─ 书库 pages/library/index ★新增
│   ├─ 搜索（防抖）+ 分类 chips（全部+5 类）
│   ├─ 书笺列表（封面/书名/作者/分类/评分/页数）
│   └─ → 书籍详情?id=
├─ 书架 pages/bookshelf/index
│   ├─ 三段 Tab：想读 n / 在读 n / 已读 n（角标+黛蓝指示条）
│   ├─ 在读卡=继续阅读+更新进度；想读卡=开始阅读；已读卡=重读
│   └─ 空态 CTA「去书库逛逛」（闭环）
└─ 我的 pages/user/center
    ├─ 用户卡（未登录=登录引导；已登录=头像/昵称/读者号）
    ├─ 三格摘要（累计/已读/连续）────→ 统计页
    ├─ 今日目标行 + 修改（10-240 分钟，写后端单一数据源）
    └─ 菜单：我的书架/阅读统计/关于我们/联系客服/用户协议/隐私政策/设置

功能页（非 Tab）
├─ 书籍详情 pages/book/detail（书库/书架/首页书单共用终点）
│   ├─ 头区（封面+书名+作者+出版社+分类+评分）★补 S1 缺示字段
│   ├─ 进度区（在架时）+ 简介（3 行折叠）
│   └─ 底栏四态（不在架/想读/在读/已读 各自的主动作）
├─ 阅读计时 pages/reading/timer（全屏沉浸 · 夜读视觉）
│   └─ 状态机 ready→running⇄paused→确认结束→成果弹层
├─ 阅读统计 pages/stats/index（自绘导航含返回键 ★修 S1 困死缺陷）
│   ├─ 三格条（今日/本周/累计）
│   ├─ 本周柱状图（当日朱砂高亮）
│   ├─ 打卡月历（钤印日格+月份切换）
│   └─ 明细四行
└─ 登录/注册/协议/客服：复用底座页（主色+标题字族换肤，不重排）
```

## 6. 选书闭环（S1 死锁的解）

```
书库（列表/搜索/分类）→ 详情 → 加入书架（想读）→ 开始阅读（转在读）→ 计时 → 统计
   ↑空态引导                                                        ↓
   └────────────────── 书架空态 CTA「去书库逛逛」 ←──────────────────┘
```

- 首页书单横滚=书库的运营位投影（最新 6 本），点更多进书库。
- 详情页底栏四态闭环：不在架=加入书架；想读=开始阅读；在读=继续阅读；已读=重读。
