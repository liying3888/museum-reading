## 1. 范围与信息架构

like-admin 前端「内容管理」域新增三页一弹层（书籍为 P0，分类 P1，看板 P1 可缓）：

```
内容管理
├─ 书籍管理（P0）
│   ├─ 列表页（搜索/分类筛选/上下架/分页）
│   ├─ 新增/编辑（抽屉表单）
│   └─ 删除（二次确认弹层）
├─ 分类管理（P1）
│   └─ 列表+行内新增/改名/停用
└─ 数据看板（P1，首期可缓）
    └─ 书籍总数/在架数/读者数/今日阅读人次（statistics 已有接口聚合）
```

## 2. 书籍列表页（板 9 画板）

### 2.1 布局

1. **顶栏**：面包屑「内容管理 / 书籍管理」+ 搜索框（书名/作者模糊，防抖 500ms）+ 主按钮「新增书籍」。
2. **筛选行**：分类下拉（全部+5 类）+ 状态下拉（全部/上架/下架）。
3. **表格八列**：书名（衬线）/作者/分类/页数/评分/状态（上架=墨绿点+字，下架=枯墨）/上架时间/操作（编辑/删除文字按钮，删除朱砂）。
4. **分页条**：右对齐「共 n 条」+页码（10/页）。

### 2.2 交互规格

- 行点击「编辑」→ 抽屉表单（数据回填）；「删除」→ 二次确认（文案含书名：删除后读者端立即不可见，书目下的阅读记录保留）。
- 「新增书籍」→ 同抽屉空表单。
- 搜索/筛选变更即重置页码拉列表。
- 空态：「还没有上架书籍」+「新增第一本书」按钮。

## 3. 新增/编辑抽屉表单

字段与 `la_book` 表对齐（S1 数据模型），必填前置：

| 字段 | 控件 | 必填 | 校验 |
|---|---|---|---|
| 书名 | Input | ✓ | ≤50 字 |
| 作者 | Input | ✓ | ≤30 字 |
| 出版社 | Input | | ≤50 字 |
| 分类 | Select（分类管理数据源） | ✓ | — |
| 总页数 | InputNumber | ✓ | 1-9999 |
| 评分 | InputNumber（0-5，步进 0.1） | | 默认空=不展示 |
| 封面 | Upload（1 张，建议 200×280） | | 缺失时读者端显示黛蓝书脊占位（03 §4） |
| 简介 | Textarea | | ≤500 字，读者端 3 行折叠（02 §3） |
| 状态 | Switch（上架/下架） | | 新增默认下架 |

- 保存成功：Toast + 抽屉关闭 + 列表刷新（新增跳第一页）。
- 编辑态保存：列表保持当前页原位刷新。

## 4. 分类管理（P1）

- 列表：分类名+书目计数+状态+操作（改名/停用）。
- 停用分类：书目需先迁移（提示「该分类下还有 n 本书」阻止直接停用）。
- 新增分类行内 Input（≤10 字）。

## 5. API 依赖（admin 侧，S3 落地清单）

| 接口 | 状态 |
|---|---|
| books 列表/详情/新增/编辑/删除 | museum 岗地基批次已统一 adminapi 路径+越权校验，按 S3 联调 |
| 分类 CRUD | la_book_category 表已有，接口按现状接 |
| 上架/下架 | 状态字段复用编辑接口（不单开接口） |
| 看板聚合 | statistics 已有（P1 可缓） |

## 6. 视觉延展（与 C 端 token 同源）

- 后台底 `paper-deep`、卡面白、主色黛蓝、选中态朱砂条（侧栏）；表格书名列衬线字族——后台与 C 端气质一体（管理员也是「书斋」的主人）。
- 不引入独立后台设计系统；间距沿用 admin 底座（Element 类组件默认）+ 自定义三处（侧栏/表头底/状态点色）。
