# 角色：长期读者

30 岁上班族，每周用小程序读书 3-4 次，书架十几本在读，靠计时器记录时长，常看统计页。走查对象为 6 张板（board03/04/05/06/08/10）+ 规格《02-小程序端交互规格》。

**走查依据说明**：本次拿到的 6 张导出图**文字层全部未渲染**（多工具交叉核验一致：所有文案/数值/角标均为色块；board05 连中部计时大数字区、书名行都未导出，上半屏纯色空底；board10 仅剩零星结构块），交互细节只能对照规格文本走查——这本身记为 P1 第 1 条。文案层视觉走查待重导出后补做。

## P1（影响使用或明显缺陷）

1. 【全部板·文字层】6 张导出图文字全部丢失（board05 计时数字区、board10 大面积区域连结构都没导出）——文案与数值层无法评审，需重导出（字体显式声明）后补一轮视觉走查。
2. 【board10 第 2 屏 paused 态提示行 / 规格 §0.3】「暂停」只是前端视觉暂停、权威时长按 end−start 墙钟计算，我接个电话暂停 15 分钟照样全计进去——计时页自己的主任务「得到一份可信的记录」被口径击穿。
3. 【board05 计时页 / 规格 §5.1 状态机】忘记点结束没有任何兜底（无最长时长封顶、无自动暂停、无超时提醒），且全站没有记录修正/删除入口（§7.1 阅读记录首期不做）——睡前忘了关，一夜空转 8 小时，今日/本周/累计全被污染且改不了。
4. 【board04 书架·在读列表】十几本在读时找书全靠肉眼：无搜索、无置顶、无手动排序，固定 update_time 倒序（§4.1.3）加单列大卡一屏只放得下约 2 张——我在读的书一多，这个页面从「管理」退化成「翻找」。
5. 【首页·继续阅读卡（规格 §1.1.3，board01 未在走查清单）】快捷入口只认 update_time 最新一本，我并行读 3-4 本时它经常指错书，而唯一的兜底路径（书架）又没有搜索置顶——高频入口和兜底路径同时失效。

## P2（体验瑕疵）

1. 【board10 第 3 屏 result 态 / 规格 §5.3】成果卡只有「好的」，没有「记录页码」直达——每次读完要回书架翻到那本书再点更新进度，最高频的闭环被拖成跨页 4 步。
2. 【board08·本周柱状图柱顶数值】分钟与 X.Yh 混排（§6.1.3：<60 显分钟、≥60 显小时）——同一张图里「35」和「1.5h」并列，扫趋势还得先心算换算。
3. 【board08·统计页整体】趋势维度只有「本周」柱状图，没有月度曲线/上周对比（§6.1）——「回望一段时间」的页面定位，对用了几周的读者两周就不够看。
4. 【board04·在读卡】移出书架只靠右滑手势（想读卡才有可见「×」，§4.2）——卡片上没有任何滑动提示，第一次想清理书架根本找不到入口。
5. 【board04·书架整体】没有批量管理（多选移出/归档），书架大扫除要逐本右滑加逐本二次确认（§4.2）——藏书到几十本后这是劝退操作。

## P3（建议）

1. 【board05·running 态「已读 n 页」行 / 规格 §5.2】计时中不能顺手记当前页码，页码信息只读不可写——建议该行可点，弹轻量页码输入。
2. 【board08·打卡月历卡】已读日不可点开下钻（当日读的哪本、几段，§6.1.4）——月历现在只是一张图案，点开当日明细才对得起「钤印」的仪式感。
3. 【board08·三格统计条】今日格只有「X 分钟」没有目标参照（§6.1.2）——想看「今天还差多少」得回首页目标卡，建议格内补 X/目标。
4. 【board03·底栏已读态「重读」按钮 / 规格 §3.1.4】重读对既有进度和「读完于」日期如何处理未定义——是清零重来还是保留历史，需要一句话说清。
5. 【board10·result 态 8 秒自动返回 / 规格 §5.1】想多看一眼或截图存档的用户会被 8 秒倒计时赶走——建议点卡即暂停倒计时。
6. 【board05·ready 态 / 规格 §1.1.3+§5.1】从首页/书架点「继续阅读」进计时页后还要再点一次「开始」——防误触可以理解，但每周 3-4 次的高频路径双跳，值得做个「直接开始」选项。

## 总评：重度用户会不会留存

骨架是真做了功课的——状态机、结束确认弹层、时区口径、目标环、打卡月历都是统计党在意的东西，页面克制没有假模块。但 P1 第 2、3 条（暂停照计时+忘记结束无兜底且不可修正）打穿的是「记录可信」这个留存根基，加上多本在读后书架翻找成本线性上升：这两组修掉我会稳定留在这里，不修的话统计被污染一次又无处修正，大概率回到手机自带计时器。
