# 角色：博物馆参观者

45 岁普通游客，不熟数码产品，在某博物馆看到「博物馆读书」小程序码扫码进入。只关心：这是干嘛的、怎么找到和博物馆展品/主题相关的书、怎么开始读。走查 board07（首页）、board02（书库）、board03（详情）、board04（书架）、board01（视觉方向板），对照 02-小程序端交互规格.md 与 03-视觉方向.md；导出图内容以 museum-pencil.pen 源节点交叉核实。

## P1（影响使用或明显缺陷）

1. board07/02/03/04/01 全部五张导出图：整图零文字——OCR 与视觉模型双通道确认图上没有任何文字，只剩色块骨架；对照 .pen 源文件文字节点齐全，属导出管线静默丢字（board04 图上连源里有的两处「×」移出键都不见了，交叉印证），且 03 视觉篇 §8 自定的「导出后行带断言预检（防静默丢字）」没有拦住——游客拿这五张图第一眼什么也认不出来，视觉走查不可用。
2. board07 首页整页 + board02 书库整页：博物馆/展品关联零入口——从首屏标题「荣河读书」到书库分类（文学/历史/科学/艺术/哲学）通篇没有博物馆/展品/馆藏字样（.pen 全文检索仅 3 处「荣河」，0 处「博物/展品」），游客扫码想找「和刚看的展品相关的书」没有任何路径；规格 01 §8.3 虽已列范围外，但角色走查须置顶暴露：这是该游客的核心诉求。
3. board07 本周书单卡作者名（加西亚·马尔克斯等）：字号 fs9（约 18rpx）且用枯墨 #A8A296，在纸面上的对比度约 2.3:1 至 2.5:1，远低于 WCAG AA 的 4.5:1——45 岁游客基本看不清；同一枯墨小字还用于首页日期、「更多 ›」「全部在读 ›」、书库页数/「没有更多了」等大量辅助信息，且与 03 视觉篇 §1.2「对比度全过 WCAG AA」的自称矛盾（该条只列 ink/ink-2/night-ink 三对，回避了实际大量使用的 ink-3）。

## P2（体验瑕疵）

1. board07 目标卡右列「本周已钤 4 印」：「钤」字超出普通游客词汇，没人知道这是「打卡记录」，第一眼像是看不懂的装饰文字。
2. board03 进度区「更新进度」按钮 / board04 在读卡同名按钮：整个界面没有一句话解释「读纸质书需要你自己记页码、回这里手动填进度」这个机制，不熟数码的游客不明白这个按钮为什么存在、什么时候该点它。
3. board03 底部操作栏（不在架态）：主动作是「加入书架」而不是「开始阅读」——想读一本书要先理解「书架」概念、加入、再从想读态点「开始阅读」，比游客直觉多一跳，第一次进详情页会犹豫。
4. board07 目标钤印卡整卡：点击卡身跳统计页（规格 §1.1），但卡上没有任何「查看统计」的暗示，可点区域不可预期，不熟数码的游客既可能误触、也可能永远发现不了。
5. board07 首屏标题「荣河读书」：游客从「博物馆读书」码进来，首屏却是个陌生馆名式雅号，没有一句副标说明「这是 XX 博物馆的伴读小程序」，扫码场景与首屏身份对不上。
6. board07/02/03/04 各页小字：画板实测存在 fs9/fs10/fs11 文字（作者 fs9、TabBar 标签 fs10、日期/页数 fs11），低于 03 视觉篇字号表 22rpx 下限、也低于其「画板示样统一 ≥24rpx」的自称——落码若照抄示样即全线低于自家规范。

## P3（建议）

1. board07「更多 ›」「全部在读 ›」与 board03 评分行「4.9 · 12.6 万人评过」：「›」「·」符号与既定设计文案口径（箭头/对号类符号禁用、「·」中点禁作间隔符）冲突，定稿前统一处理（本条依 .pen 文字节点提出，导出图上不可见）。
2. board07 底部 TabBar：选中态仅靠黛蓝/淡墨颜色区分，无字重或填充差异，色弱或老花游客难辨当前在哪页。
3. board04 书卡右上「×」移出键：fs14 枯墨色，目标偏小偏浅（有二次确认兜底，故仅建议）——对不熟数码的游客建议加大热区或改文字「移出」。
4. board03 页首返回键「‹」：单个文字符号 fs22，视觉上细弱，落码时按 03 §5 自定导航规范保证热区 ≥88rpx 并考虑换自绘线性箭头。

总评：如果看「有文字的设计」本身，这位游客的路径是通的——首页书单或书库找到书、进详情、开始阅读、读完盖章，一步一步都算清楚，宣纸底、黛蓝、朱砂印的气质放在博物馆场景里也得体，不像廉价工具 App；但按当前交付的导出图走查，五张「无字底版」让他第一眼什么也认不出，而且翻遍整个产品也找不到和刚逛完的博物馆有关的任何书或字样。他会学会用它读书，却说不清它和这座博物馆有什么关系——愿不愿意再来，取决于书单内容能不能和他馆内所见接上。
