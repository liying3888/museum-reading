# 角色：博物馆管理员

40 岁文化活动岗，非 IT。每天在后台录新书、改分类、下架；每周看一眼整体阅读数据给馆里汇报。走查路径：板 9 列表页 → 点「新增书籍」→ 表单 → 保存；对照 04 规格（§2 列表 / §3 表单）与 03 视觉方向；板 8 看 C 端读者视角。

前置说明：board09-admin.png（OP 版）与 board08-stats.png（OP 版）经像素级核验**整板无文字**（侧栏零白字、正文零墨色像素），走查实际依据 Pencil 双轨版（board09-admin-pencil.png / board08-stats-pencil.png）+ 规格文档；OP 版丢字本身已列为 P1。

## P1（影响使用或明显缺陷）

- 【board09 两版 · 全板】新增/编辑抽屉表单与删除确认弹层**一张都没画**：两版画板下半约半幅空白，只画了列表页；我点「新增书籍」后要填什么、长什么样、必填怎么提示、保存键在哪，全部无设计（04 §3 只有字段表无布局）。录入新书是我每天的主活，主链路从按钮点下去就断。
- 【board09-Pencil · 顶栏与表头之间】规格承诺的**筛选行（分类下拉+状态下拉）没画**（04 §2.1.2）：Pencil 版该区域只有一行悬浮表头小字，无任何下拉控件；书一多我没法按分类/状态缩小范围，「快速找到某本书改信息」缺一环。
- 【board09-admin.png · 全板】**OP 版导出整板丢字**：全图无一个文字像素（侧栏菜单、表头、数据行、按钮全空），且表格左下多出两个无字白块、无分页条，结构也错乱；同批 board06/board08 同病（10 板丢 3），「导出后行带断言预检（防静默丢字）」未拦住。04 文档头挂的配套画板正是这块 OP 版——交付物不可用，需重导+预检补拦。

## P2（体验瑕疵）

- 【board09-Pencil · 表头行 y≈164-182，白卡 y≈212 起】**表头悬浮在卡片外**：底色与页面底同色（米色）、下无边线，与数据卡隔一段空白，「书名 作者 分类…」那行小字第一眼像页面装饰说明，不像列头。
- 【board09-Pencil · 状态列】**状态列无墨绿点、上架字色与正文相同**：04 §2.1.3「上架=墨绿点+字」未兑现；下架只是淡一点，扫读时分不清哪些书读者此刻能看到——这列是我决定汇报口径的依据。
- 【board09-Pencil · 书名列】**书名衬线判读未生效**：3x 放大下「三体」与「刘慈欣」同为无衬线常规体，04 §2.1.3/§6 承诺的「书名列衬线（与 C 端书斋气质一体）」没兑现，与 C 端统计页衬线大数字的呼应断了（需查源文件是否字体未声明，OP 已知坑）。
- 【board09-Pencil · 操作列】**删除（朱砂红）紧挨编辑、间距小**：怕手滑点错；承诺的二次确认弹层又没画（见 P1 第 1 条），确认文案「含书名+影响说明」实际长什么样无从核对。

## P3（建议）

- 【04 §3 · 评分字段】评分建议用星级控件而非数字输入框：给书打 4.6 分靠手输数字+小数点（0-5 步进 0.1）不直观，点星星更符合直觉，也与 C 端评分星语义一致。
- 【04 §2.1.3 vs 03 §1.2 · 用色口径】删除用色文档打架：04 说「删除朱砂」，03 配色律说「危险操作用 fail 色，朱砂是仪式色不混用」，画板用了朱砂——落码前两份文档定一个（作为使用者我只求红色醒目）。
- 【board09-Pencil · 顶栏面包屑】面包屑「内容管理 / 书籍管理」与侧栏平铺六菜单（数据看板/书籍管理/分类管理/读者管理/打卡统计/系统设置）层级对不上，侧栏并无「内容管理」分组。
- 【board09-Pencil · 分页条】示样「共5条」却排了两个页码（规格每页 10 条应只有 1 页）——示样数据自洽问题。
- 【board09 · 表格列】可考虑加封面缩略图小列：找书时认封面比认字快，C 端书库本来就是封面卡形态。
- 【board09-Pencil · 侧栏标题】「荣河·书斋后台」用中点「·」作间隔符，踩 10-24 文案禁符线（中点禁作间隔符，改顿号/空格/从属括号）。

## 总评：非 IT 人员敢不敢天天用

骨架和气质是对的：米白纸面+黛蓝侧栏+朱砂选中条与 C 端一体，「新增书籍」按钮在右上好找，规格里新增默认下架、删除带书名的二次确认这些心思都对路。但这一版我不敢签收：录书的关键画面（表单/确认弹层）一张没有、找书的筛选器没画，交到我手上的 OP 版导出图还是整板没字——照它培训值班同事会当场露馅。补上表单、筛选行、确认弹层三张画并修状态点与表头归属感，就能放心天天用。
