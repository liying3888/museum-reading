## 0. 通用约定

### 0.1 请求与数据

- 全部请求走统一封装（底座 `utils/request`），**url 一律不带 `/api` 前缀**（拦截器统一拼），调用层解包约定：`request.get()` 直接 resolve 业务 `data`，页面**不再取 `res.data`**（修 S1 全站解包 bug）。
- 业务接口需登录态：token 由底座 `like-token` header 携带；后端从 token 解 userId（S3 改造，替换 `userId=1` 硬编码）。
- 每日目标分钟数**单一数据源**：后端用户配置（首期默认 30，我的页可改，范围 10-240）——首页/我的/统计三处展示同一值（修 S1 三处不一致）。

### 0.2 页面状态四件套（每页必答）

| 状态 | 全局样式 |
|---|---|
| 加载 | 骨架屏（卡片灰阶占位）或页面级 loading；请求超时 10s（封装默认） |
| 空数据 | 线性插画+文案+动作按钮（见 01 §4） |
| 失败 | Toast 提示 + 页面保留旧数据或空态；不白屏 |
| 未登录 | 需登录页（Tab 中书架/我的的未登录态）：引导卡+「登录」按钮跳底座登录页，登录成功回跳原页 |

### 0.3 计时口径（前后端统一契约）

- 前端显示时间 = `record.start_time` 起算的服务器秒差，onShow 时重算（**修 S1 切后台漂移**）；
- 本地 setInterval 仅做秒级跳动渲染，不作为时长依据；
- 暂停仅是前端视觉暂停（提示"计时后台仍在进行"）；权威时长 = 后端 `end - start` 墙钟。

## 1. 首页 `pages/index/index`

**主任务：回答"我今天读了吗"，并给出最快的继续阅读入口。**

### 1.1 布局（自上而下）

1. **页首区**：衬线标题「荣河读书」+ 右侧日期（`11月3日 · 星期二`，24rpx 淡墨）。
2. **今日目标钤印卡**（主卡，纸笺样式；**点击卡身 → 统计页**，01 §3 统计入口之一）：
   - 左：目标环（直径 200rpx 圆环进度，朱砂描边）内嵌「已读 X 分钟 / 目标 30」；
   - 右：连续打卡 n 天（衬线数字）+ 本周已钤 m 印；
   - 完成态（X≥目标）：环满 + 右上角盖「今日已阅」朱砂圆印（0.4s 盖印动效）。
3. **继续阅读卡**（仅在读 >0 时显示）：封面缩略 + 书名（衬线）+ 「第 n 页 / 共 m 页」+ 朱砂进度条 + 主按钮「继续阅读」→ 计时页（带 bookId/bookTitle）。多本在读时取 update_time 最近一本，卡右下「全部在读 →」跳书架在读 Tab。
4. **本周书单区**：区标题「本周书单」+「更多 →」（跳书库）+ 横向滚动书卡（封面+书名+作者，点击 → 详情）。书单来源：书籍列表接口按运营置顶/最新（首期=最新 6 本，S1 的假"活动/笔记"模块**删除**，修 S1 缺陷）。
5. 无第 3 区时：书单区上移，页面自然收尾（不做占位假模块）。

### 1.2 交互细节

- 进入时序：先渲骨架，`Promise.all` 并发拉 [今日统计, 在读书架, 书单]；任一失败独立降级（目标卡失败显示「--」+重试小按钮）。
- onShow 刷新目标与在读（从计时页返回能看到最新数字）。
- 下拉刷新：全量刷新。

### 1.3 未登录态

目标卡显示「登录后记录你的阅读」+ 登录按钮；其余区块正常展示（书单是公开数据）。

## 2. 书库 `pages/library/index`（★新增页）

**主任务：找到下一本要读的书。（S1 选书死锁的解）**

### 2.1 布局

1. **搜索框**（顶部吸顶）：placeholder「搜书名 / 作者」，输入即防抖 500ms 调列表接口；清空按钮。
2. **分类 chips 横向滚动**：「全部」+ 分类列表（数据源 `books/list` 的分类聚合或分类接口，首期 front 端简化为全量分类常量+接口过滤）。
3. **书卡列表**（单列纸笺卡）：左封面（160×220rpx，缺失显示黛蓝书脊占位图——**修 S1 裂图**，占位图随包内置）+右侧书名（衬线）/作者/分类标签/评分（铜金星+数值）/页数。点击 → 详情。
4. 分页：滚到底自动加载下一页（15/页），列表尾部「没有更多了」。

### 2.2 交互细节

- chips 切换重置页码；搜索与 chips 叠加过滤。
- 空结果：插画+「没有找到相关书籍」+「清除筛选」按钮。
- 请求失败：列表区顶部黄条提示+点击重试。

## 3. 书籍详情 `pages/book/detail`

**主任务：了解一本书，并开始与它的关系（收藏或阅读）。**

### 3.1 布局

1. **书籍头区**：封面（200×280rpx）+ 右侧：书名（衬线 36rpx）、作者、出版社、分类标签、评分行（星+分值+人数）。**出版社/分类为表内已有字段补展示（修 S1 有数据不显示）**。
2. **进度区**（已在书架时显示）：「阅读进度 n%」朱砂进度条 + 「第 x 页 / 共 m 页」+ 「更新进度」次按钮。
3. **简介区**：默认收起 3 行 + 「展开」；展开后全文 +「收起」。
4. **底部操作栏**（固定）：
   - 不在架：主按钮「加入书架」；
   - 在架（想读）：主按钮「开始阅读」+ 次按钮「移出书架」；
   - 在架（在读）：主按钮「继续阅读」+ 次按钮「更新进度」；
   - 在架（已读）：主按钮「重读」+ 文字按钮「查看书架」。

### 3.2 交互细节

- **更新进度**（弹层）：页码步进器（-10/+10、-1/+1、直接输入），输入范围 0~总页数；保存 → 进度接口 → 刷新进度区；达到总页数时弹确认「标记为已读？」→ status=2。
- 加入书架成功：Toast「已加入书架 · 想读」+ 底栏切换为在架态（不整页刷新）。
- 移出书架：二次确认弹层（确认后书架记录删除——S3 补 delete 接口或 status 软删，规格先立）。
- 页面数据：`books/detail` + `bookshelf/list`（判定在架状态；**修 S1 的 status:-1 传参错误**：在架判定用不带 status 的全量列表）。

## 4. 书架 `pages/bookshelf/index`

**主任务：管理我的书与进度。**

### 4.1 布局

1. **三段 Tab**（吸顶）：「想读 n」「在读 n」「已读 n」（计数角标，黛蓝下划指示条；**修 S1 圆块 Tab**）。默认停「在读」。
2. **书卡列表**（单列）：
   - 想读卡：封面+书名+作者+右上次按钮「开始阅读」+「×」移出；
   - 在读卡：+进度条+页码行+双按钮「继续阅读 / 更新进度」；
   - 已读卡：+「读完于 yyyy-mm-dd」+「重读」文字按钮。
3. 排序：update_time 倒序（沿用后端）。

### 4.2 交互细节

- Tab 切换：滑动手势支持（左滑右滑切 Tab）+ 点击。
- 「开始阅读」：调 progress 接口（current_page 从 0 起）自动转在读态 + 跳计时页。
- 移出书架：卡片右滑露出「移出」或「×」点击 → 二次确认。
- 空态（分 Tab 文案不同）：想读=「还没有想读的书，去书库逛逛」+主按钮；在读=「从书库选一本书开始读吧」；已读=「读完一本书，就会在这里留下印记」。
- 分页+下拉刷新同书库。

## 5. 阅读计时 `pages/reading/timer`（全屏沉浸 · 夜读视觉）

**主任务：专注阅读，结束时得到一份可信的记录。**

### 5.1 状态机

```
ready --点击开始(调start接口成功)--> running
running --暂停--> paused --继续--> running
running/paused --点击结束--> confirm(弹层) --确认(调end接口)--> result
result --确定/自动(8s无操作)--> 返回来源页
【离开页面(含物理返回)时 running/paused → 不弹确认直接后台继续计时，Toast提示"计时仍在进行"】
```

**修 S1 两缺陷**：① start 接口成功才进入 running（失败 Toast+停留 ready，杜绝"点了没反应"；调用层已无 res.data 解包问题）；② 结束前必须过确认弹层（防误触）。

### 5.2 布局（running 态）

- 上：书名（28rpx 暖白 65%）；
- 中：衬线大数字 `HH:MM:SS`（约 120rpx，tabular-nums）；其下小字「已读 n 页」（带 bookId 时）；
- 下：双按钮「暂停 / 结束」；paused 态显示「继续 / 结束」+ 提示行「已暂停 · 计时后台仍在进行」。

### 5.3 成果弹层（result）

- 居中纸笺卡：标题「本次阅读」+ 衬线大数字时长（X 小时 Y 分）+ 三行小结（今日累计 / 连续打卡 n 天 / 距今日目标差 z 分钟）+ 朱砂小印装饰；
- 按钮「好的」返回；当日目标达成时卡片顶部盖印动效+文案「今日目标达成」。

### 5.4 边界

- onShow：按 §0.3 重算显示时间（修漂移）；
- 结束接口失败：停留 running + Toast 重试提示，记录不丢（后端墙钟仍在走）；
- 无 bookId 进入（从首页快速开始）：书名行显示「自由阅读」，成果页提示「下次可从书架选书记录页码」。

## 6. 阅读统计 `pages/stats/index`（自定义导航含返回）

**主任务：回望一段时间的阅读。**（不占 Tab 位；入口两条=我的菜单+首页目标卡点击，见 01 §3。**修 S1 无返回键缺陷**：自绘导航栏 = 返回箭头+标题「阅读统计」）

### 6.1 布局

1. **自绘导航**：左返回箭头（返回上一页或 Tab）+居中标题。
2. **三格统计条**（横排纸笺卡）：今日 X 分钟 / 本周 Y 小时 / 累计 Z 小时（衬线数字，点击格内无跳转）。
3. **本周柱状图卡**：7 柱（周一~周日），柱高按周内 max 归一（max=0 时全柱显示基线+「本周暂无记录」）；柱顶数值分钟（<60 直接显示分钟，≥60 显示 X.Yh），当日柱朱砂高亮、其余黛蓝。**修 S1：px/rpx 统一 rpx、数值自适应单位、不再悬浮裁切。**
4. **打卡月历卡**（钤印）：月历网格 7 列，月份切换（左右箭头，范围：注册月~当月）；已读日=朱砂小方印反白日期，未读日=淡墨数字，未来日=极淡；月标题「2026 年 11 月 · 已读 n 天」。
5. **明细行卡**：阅读天数 / 在读书籍 / 读完书籍 / 书架总数 四行（label 左 value 右衬线数字）。

### 6.2 交互细节

- 数据源 `stats/overview` 一次拉全；月历切换按月增量请求（S3 补 checkin 月参数化接口，首期可一次取回后前端过滤）。
- 打卡判定用东八区日期（**修 S1 UTC 串时区错位**：后端返回 yyyy-MM-dd 本地日期数组）。
- 未登录：整页登录引导。

## 8. 全局交互补充

- **TabBar**：四项（见 00 §2.1），图标线性+选中黛蓝，未选枯墨；中间无凸起。
- **页面转场**：系统默认；详情/计时为 navigateTo，书库/书架/我的/首页为 switchTab/reLaunch。
- **手势**：书架 Tab 横滑切换；详情简介展开收起；列表下拉刷新（书库/书架/首页/统计）。
- **错误码统一处理**：332/登录失效 → 底座 logout+跳登录（保留回跳）；其余 Toast msg。
