## 0. 通用约定

### 0.1 请求与数据

- 全部请求走统一封装（底座 `utils/request`），**url 一律不带 `/api` 前缀**（拦截器统一拼），调用层解包约定：`request.get()` 直接 resolve 业务 `data`，页面**不再取 `res.data`**（修 S1 全站解包 bug）。
- 业务接口需登录态：token 由底座 `like-token` header 携带；后端从 token 解 userId（S3 改造，替换 `userId=1` 硬编码）。
- 每日目标分钟数**单一数据源**：后端用户配置（首期默认 30，我的页可改，范围 10-240）——首页/我的/统计三处展示同一值（修 S1 三处不一致）。

### 0.2 页面状态四件套（每页必答）

| 状态 | 全局样式 |
|---|---|
| 加载 | 骨架屏（卡片灰阶占位）或页面级 loading；请求超时 10s（封装默认） |
| 空数据 | 线性插画+文案+动作按钮（见 01 §4） |
| 失败 | Toast 提示 + 页面保留旧数据或空态；不白屏 |
| 未登录 | 需登录页（Tab 中书架/我的的未登录态）：引导卡+「登录」按钮跳底座登录页，登录成功回跳原页 |

### 0.3 计时口径（前后端统一契约，11-03 round1 修订：暂停改真暂停）

- 前端显示时间 = 服务器净时长（`start` 起算的秒差 **减去已累计暂停段**），onShow 时重算（**修 S1 切后台漂移**）；
- 本地 setInterval 仅做秒级跳动渲染，不作为时长依据；
- **暂停是真暂停**（round1 双角色 P1 修订）：pause/resume 各记一时间点，权威时长 = `Σ(运行段)` = `end − start − Σ暂停段`，暂停期间时长不走（提示行「已暂停 计时已同步暂停」）；离开页面不中断计时但暂停态保持；
- **忘记结束兜底**（round1 P1 修订，三层）：①单次计时达 120 分钟：计时页弹提醒「已读 2 小时，要继续吗」（继续/结束）②达 240 分钟自动结束并落记录（异常标记 `auto_closed=1`，成果弹层注明「长时间未操作已自动结束」）③记录修正入口：我的页-设置内「阅读记录管理」（按日列表，可删除异常记录，删除需二次确认并说明影响：今日/本周累计同步重算）。
- **240 分钟自动结束的执行主体**（round2 P1④ 补文）：**后端权威**——到点判定与落记录均由后端完成（服务端墙钟扫描运行中会话，达 240 分钟即结束并标 `auto_closed=1`），不依赖前端在线；前端在场时同步触发结束调用（双通道），重复结束以后端已有记录幂等返回，不产生双记录。用户杀进程/断网/离线场景下，下次拉取记录时即可见该自动结束记录。
- **paused 会话的扫描口径**（round3 P2-4 补缝）：上条扫描范围=**running+paused 两态并集**（暂停忘结束的会话同样到线结算，不悬挂）。240 分钟线按**墙钟**自 start 起算（暂停时间计入墙钟——暂停不能无限拖延自动结束）；被自动结束的 paused 会话，其净时长按已累计运行段 `Σ(运行段)` 结算落记录（时长口径与 §0.3 真暂停一致，跨天归属取结束时刻所在日）。

## 1. 首页 `pages/index/index`

**主任务：回答"我今天读了吗"，并给出最快的继续阅读入口。**

### 1.1 布局（自上而下）

1. **页首区**：衬线标题「荣河读书」+ 右侧日期（`11月3日 星期二`，24rpx 淡墨）。
2. **今日目标钤印卡**（主卡，纸笺样式；**点击卡身 → 统计页**，卡右上小字「查看统计」暗示可点（round1 修订：可点区域可预期））：

   - 右：连续打卡 n 天（衬线数字）+ 本周打卡 m 天（round1 修订：「已钤 m 印」改直白口径，钤印概念留统计页月历处有注释行解释）；
   - 完成态（X≥目标）：环满 + 右上角盖「今日已阅」朱砂圆印（0.4s 盖印动效）。
3. **继续阅读卡**（仅在读 >0 时显示）：封面缩略 + 书名（衬线）+ 「第 n 页 / 共 m 页」+ 朱砂进度条 + 主按钮「继续阅读」→ 计时页（带 bookId/bookTitle）。多本在读时**点卡身弹「在读快选」半屏抽屉**（在读列表直选一本书进计时，round1 修订：update_time 单一取本常指错书）；卡右下「全部在读 →」跳书架在读 Tab。

5. 无第 3 区时：书单区上移，页面自然收尾（不做占位假模块）。

### 1.2 交互细节

- 进入时序：先渲骨架，`Promise.all` 并发拉 [今日统计, 在读书架, 书单]；任一失败独立降级（目标卡失败显示「--」+重试小按钮）。
- onShow 刷新目标与在读（从计时页返回能看到最新数字）。
- 下拉刷新：全量刷新。

### 1.3 未登录态

目标卡显示「登录后记录你的阅读」+ 登录按钮；其余区块正常展示（书单是公开数据）。

## 5. 阅读计时 `pages/reading/timer`（全屏沉浸 · 夜读视觉）

**主任务：专注阅读，结束时得到一份可信的记录。**

### 5.1 状态机

```
ready --点击开始(调start接口成功)--> running
running --暂停(记pause点)--> paused --继续(记resume点)--> running
running/paused --点击结束--> confirm(弹层) --确认(调end接口)--> result
result --确定/自动(8s无操作)--> 返回来源页
running --达120分钟--> remind(继续/结束) ；达240分钟--> 自动结束(auto_closed) --> result
【离开页面(含物理返回)时 running/paused → 不弹确认直接后台计时保持当前态，Toast提示"计时仍在进行"；暂停态离开则保持暂停不走时】
```

**修 S1 两缺陷**：① start 接口成功才进入 running（失败 Toast+停留 ready，杜绝"点了没反应"；调用层已无 res.data 解包问题）；② 结束前必须过确认弹层（防误触）。

**状态画板**：`boards/board10-states.png`——ready（开始前 00:00:00 弱显）/ paused（暂停视觉态+「已暂停 计时已同步暂停」提示）/ result（夜底纸笺成果卡：朱砂「已阅」印+本次时长+累计/连续/目标三行+8 秒自动返回）。

### 5.2 布局（running 态）

- 上：书名（28rpx 暖白 65%）+ 右端态标胶囊「计时中」（描边小胶囊，round7 回写 b5 实况；paused 态胶囊换「已暂停」）；
- 中：衬线大数字 `HH:MM:SS`（约 120rpx，tabular-nums）；其下小字「已读 n 页」（带 bookId 时）；
- 下：双按钮「暂停 / 结束」（round1 修订主次：**暂停/继续=暖白实底主按钮**（阅读中最高频操作），**结束=反白描边次按钮**（终态操作有确认弹层兜底）；旧版结束实底的主次颠倒已改）；paused 态显示「继续 / 结束」+ 提示行「已暂停 计时已同步暂停」；running 态底部常驻提示「计时中 可切后台不打断」；ready 态提示行「开始后计时 暂停即同步暂停」（00:00:00 弱显下方，round7 回写 board10 实况）。

### 5.3 成果弹层（result）

- 居中纸笺卡：标题「本次阅读」+ 衬线大数字时长（X 小时 Y 分）+ 三行小结（今日累计 / 连续打卡 n 天 / 距今日目标差 z 分钟）+ 朱砂小印装饰；
- 按钮「好的」返回；当日目标达成时卡片顶部盖印动效+文案「今日目标达成」。

### 5.4 边界

- onShow：按 §0.3 重算显示时间（修漂移）；
- 结束接口失败：停留 running + Toast 重试提示，记录不丢（后端墙钟仍在走）；
- 无 bookId 进入（从首页快速开始）：书名行显示「自由阅读」，成果页提示「下次可从书架选书记录页码」。
- **悬置会话重入**（round2 P1④ 补文）：存在进行中会话（running/paused）时再进计时页（首页继续阅读/书架继续阅读入口）——**不新建会话，恢复该会话当前态**：running 恢复 running 并按 §0.3 重算显示；paused 恢复 paused（提示行照旧）。入口文案联动：有进行中会话时首页/书架按钮显示「回到计时」语义（同书直进）；S3 落地为 start 接口幂等（带未结束会话则返回该会话而非新建）。
- **异书重入口径**（round3 P1-3 补缝；round4 补态分支）：入口点的是**另一本书**（存在未结束的 A 书会话，却从 B 书详情/书卡点「开始阅读」）——start 幂等仍返回现存 A 书会话（不新建、不串页码），前端据返回的书名与**会话态**提示并提供出口按钮「结束并开新书」（round4 口径：running=「回到《A》计时中」；paused=「回到《A》已暂停的计时」——A 既已暂停，不得称「计时中」）：点击=先走 A 会话结束确认弹层（§5.1），确认结束后原地以 B 书发起 start。**链式收尾口径**（round4 补注）：此路径顺带结束 A 时**跳过 A 的成果弹层**（A 时长已落阅读记录，成果弹层仅为达成仪式的呈现；在「开新书」动线上再弹 A 成果会打断流程，属预期内取舍——想回看 A 成果可事后进统计页）。**禁止**静默把用户放进 B 书计时页（会把跨书错乱固化为接口行为）；也**不做**「自动结束 A 会话」（用户可能只是点错，A 会话的时长由本人决定去留）。
