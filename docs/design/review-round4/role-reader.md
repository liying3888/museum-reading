## 二、02 规格两缝场景推演（R3 P1-3 + P2-4）

### 1. 行 168 异书重入口径——**补缝完整，场景闭环，销案 ✓**

以读者身份推演「暂停三体→点百年孤独开始阅读」全链：
1. 我在 B 书详情/书卡点「开始阅读」→ start 幂等返回 A（三体）会话，B 未被新建，页码不串 ✓；
2. 前端按返回书名提示「回到《三体》计时中」并给「结束并开新书」出口 ✓；
3. 点出口→A 结束确认弹层→确认→原地开 B 计时；在弹层取消→留在 A，A 时长无损 ✓；
4. 我若不点出口也无死路：常规路径（A 计时页结束按钮→确认→回书架→开 B）照常可达 ✓；
5. 入口枚举（B 书详情/书卡）为示例性写法，机制层由 start 幂等统一覆盖——首页快选抽屉选 B 走同一 start，同样落入本口径 ✓。

推演中发现的两个措辞级小缝（均 P3 记账，不拦销案）：
- **paused-A 文案不合**：A 是暂停态时提示「回到《三体》**计时中**」与 A 实态（已暂停、时长冻结）措辞矛盾——建议 paused 会话时文案自适应为「《三体》计时已暂停」一类；
- **链式结束跳过 A 成果弹层**：确认结束后原地直开 B，A 的本次时长不入眼（记录照落、可后查，且 §5.1 弹层文案已预告「结束后生成阅读记录」）——可接受的设计取舍，但链式场景下 A 结束确认弹层若加一句「结束后将开始《百年孤独》」预期更完整。备忘不立案。
