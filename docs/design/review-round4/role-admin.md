# 角色：博物馆管理员 R4（定向抽验·收口轮）

40 岁文化活动岗，非 IT。每天录新书、改分类、下架旧书。本轮只验我 R3 提的修复条目（控件三缺 P2 + P3×4）+ board12 全帧新伤快扫，不全量重验。对照 04 §2.2/§3、06 §5/§7/§7a、design 回执 commit 64782d01（P2-7「Select 矢量 V 箭头/页数评分步进钮(ASCII 形状 dump)/Upload 虚线框+加号」+P3 批含帧 B 标点/抽屉✕/帧 C 空态/04 头挂板）。

方法纪律（本轮新增强记录）：按派单要求以结构证据回敬结构自证——每个控件做了逐行游程 ASCII dump（每字符 1px），与 design 声称的形状逐顶点比对。**另记一次方法论事故**：帧 C 大幅裁片经查看通道渲染连续四次出现不存在的元素（C 端胶囊页头/筛选行/八列表头/书本书谱图——均被同区域像素穷举当场证伪，外部 OCR 复核与穷举一致），本轮所有帧 C 结论一律以像素穷举+外部 OCR 双源定案，大幅渲染图一律不作为证据。此坑与 097 坑谱「判读双向不可靠」同族，建议后续走查角色知悉。

- 修法：两线段改 V（三点两段折线：左上→下中←右上），或直接换 ▾ 矢量，量级 5 分钟。
