## 1. 色板（设计 token，S3 落 CSS 变量，画板变量集同名）

### 1.1 语义色

| Token | 色值 | 用途 |
|---|---|---|
| `paper` | `#F8F5EF` | 全局底色（宣纸米白） |
| `paper-deep` | `#F1ECE1` | 分区底/按压态底 |
| `card` | `#FFFFFF` | 卡片面（纸笺） |
| `ink` | `#2C2A26` | 主文字（墨色，非纯黑） |
| `ink-2` | `#6B675E` | 次要文字（淡墨） |
| `ink-3` | `#A8A296` | 辅助/占位（枯墨） |
| `line` | `#E8E2D6` | 分割线/描边（绢色线） |
| `indigo` | `#2F4154` | **主色**：导航/强调/主按钮（黛蓝） |
| `indigo-deep` | `#243342` | 主按钮按压态 |
| `cinnabar` | `#B03A2E` | **点睛**：印章/进度/打卡（朱砂，单屏≤2 处） |
| `cinnabar-soft` | `#F5E3DE` | 朱砂浅底（标签底/高亮底） |
| `night` | `#1E2B38` | 计时页底（墨夜蓝，沉浸专用） |
| `night-ink` | `#F4EFE6` | 计时页前景（暖白） |
| `gold` | `#B8935A` | 评分星/勋章点缀（铜金，低频） |
| `ok` / `warn` / `fail` | `#4A7A5E` / `#B8863B` / `#A84234` | Toast/表单反馈（降饱和融于纸面） |

### 1.2 配色律

1. 纸面三层封顶：`paper`（底）→ `card`（卡）→ `paper-deep`（卡内分区/按压），不多嵌套。
2. 朱砂是仪式色不是功能色：进度/打卡/完成态可用；危险操作用 `fail`，不混用。
3. 禁渐变按钮/渐变底（S1 全站紫渐变=头号替换对象）；唯一例外=计时页夜空极轻微纵向明度渐变（`#243342→#1A2530`）。
4. 对比度：正文与可交互元素过 WCAG AA——`ink/paper`≈12.9:1、`ink-2/card`≈5.6:1、`night-ink/night`≈11.4:1。**边界条款**（round3 P2-6 勘误，原「对比度全过 AA」表述不准）：`ink-3` 枯墨（对 `card`≈2.5:1）**仅限标注层与占位符**（画板规格注记、表单 placeholder、禁用态），**不得用于产品可读文案与可点元素**——产品文案（含弹层卡内说明行、列表辅助信息、链接感文字如「查看统计」）最低 `ink-2` 淡墨档；画板内凡枯墨承载产品语义处一律升 `ink-2`（board07「查看统计」已按此修正）。

## 3. 间距与布局档位（轻阅读呈现的落地）

- **间距八档 rpx**：8 / 16 / 24 / 32 / 48 / 64 / 96 / 160（页面级留白从 160 起——轻阅读感的密度基线）。
- **页面左右边距**：32rpx；卡片内边距 24rpx；卡片间距 24rpx；区组间距 48rpx。
- **一屏一事**：每页一个主任务区（01 §2 原则的量化——首屏主任务区占屏 ≥55%，辅助区不挤压）。
- 圆角三档：卡 12rpx、弹层顶 24rpx、印/圆徽 full。

## 4. 图标与图形语言

- **图标**：线性描边统一（stroke 1.5px、24×24 网格、圆角端点），墨色；选中黛蓝。**画板已自绘 17 枚**（TabBar 4+菜单 7+功能 6，板 1 图标体系区可查），S3 按 SVG sprite 逐枚落码，**全量替换 emoji**。
- TabBar 图标语义：首页=卷轴、书库=立册、书架=书堆、我的=印章人；TabBar 选中态=图标与文字黛蓝，未选淡墨（**round2 口径注：首期仅色区分，字重/图标填充变化留迭代**）。
- **画板注记**（各板 10-11px 枯墨小字，如「02 §4.1」引用行）为**画板标注层**（说明规格出处与状态口径），非产品 UI 元素，落码不实现——枯墨低干扰是既定呈现。
- **封面占位（书笺式）**：黛蓝三档底色轮换（`indigo/#3A4E63/#243342`）+左侧深脊条（宽约 9%）+底部书口浅条（高约 13% 白 18%）——无封面图的书的体面替代。**档色按书分配**（round2 口径补定）：同一本书全稿同一档色（封面色=书属性，跨板一致；示样映射：三体 `#3A4E63`、百年孤独 `#243342`、明朝那些事儿 `#2F4154`），相邻卡错档呈现；整体黛蓝系是书笺占位的既定语言，非「深蓝一片」缺陷。
- **印章元素**（点睛，仅打卡体系）：
  - 月历日格印：12×12 圆角小方印，朱砂底反白日期；
  - 首页完成徽记：圆形「阅」字印（0.4s 盖印动效 1.2→1.0+透明度落定）；
  - 印面 1px 内描边模拟印泥边缘，**不做纹理贴图**（跨端渲染不可控）。
- 卡片（纸笺）：圆角 12rpx、描边 1px `line`、**阴影全局启用** `0 2rpx 8rpx rgba(44,42,38,0.06)`（纸感三层=底色+描边+轻投影；夜底卡不加）。
- 按钮：主=黛蓝实底白字 12rpx 圆角高 88rpx；次=白底黛蓝描边；文字=黛蓝。**废除大胶囊+渐变**。

## 5. 组件风格基线

| 组件 | 规格 |
|---|---|
| 进度条 | 高 8rpx 圆角，底 `paper-deep`，填充朱砂，右端百分比 24rpx |
| 环形进度（首页目标环） | 双层：背景满环 `paper-deep`+前景朱砂弧（圆头端点，缺口示剩余） |
| 柱状图（本周阅读） | 柱顶圆角 3px，当日朱砂、其余黛蓝，柱高按周内 max 归一 |
| Tab（书架三段） | 文字+底 4rpx 短指示条（黛蓝），角标 `ink-3` 22rpx |
| chips（书库分类） | 高 56rpx 胶囊，选中黛蓝实底白字，未选白底墨字描边 |
| 空态 | 线性插画（书/印主题）+一句文案+一个动作按钮，居中，上下留白≥160rpx；**round2 首期口径：插画=极简线性图标点缀（18-24px 书/印/放大镜/人形简笔），全幅插画留迭代** |
| Toast | 系统样式，色按 §1.1 |
| 弹层（成果/确认/进度） | 底部半屏抽屉或居中纸笺卡（顶圆角 24rpx）；**确认类弹层必带 1-2 行影响说明**（round2 密度口径：B 端删除=两行「读者端立即不可见+阅读记录保留」、C 端结束=一行「结束后生成阅读记录」），输入类弹层仅注范围（步进/上下限），不放多余说明。**弹层卡内文案用色一律 `ink-2` 淡墨档**（round3 P3② 定界：说明行/范围注是产品文案非画板标注，枯墨两制就此统一——board11 更新进度/目标设置/结束确认三弹层说明行已按此归一） |
| **自绘导航**（全部功能页） | 高 88rpx：左返回键（24×24 线性箭头，热区≥88rpx）+居中标题 34rpx 衬线；**修 S1 统计页困死** |

## 6. 计时页专属（夜读场景）

- 底 `night`（可极轻渐变），中央暖白衬线大数字 120rpx tabular-nums；书名副行 28rpx `rgba(244,239,230,0.65)`。
- 控制按钮主次（11-03 round1 修订，与 02 §5.2 同源）：**暂停/继续=暖白实底主按钮**（阅读中最高频操作，字色 `night`）；**结束=反白描边次按钮**（`rgba(244,239,230,0.4)` 描边+暖白字，终态操作有确认弹层兜底）。旧版「结束实底」的主次颠倒已改。
- 暂停态：数字透明度 0.5+提示行「已暂停 计时已同步暂停」（真暂停口径见 02 §0.3）。
