- **概念**：数字书斋 · 钤印为证（见 00 §1.2）
- **配套画板**：`画板/` 目录（视觉方向板：色板/字体/组件/关键页示意）

## 1. 色板

### 1.1 语义色（设计 token，S3 落 CSS 变量）

| Token | 色值 | 用途 |
|---|---|---|
| `--paper` | `#F8F5EF` | 全局底色（宣纸米白） |
| `--paper-deep` | `#F1ECE1` | 分区底/按压态底 |
| `--card` | `#FFFFFF` | 卡片面（纸笺） |
| `--ink` | `#2C2A26` | 主文字（墨色，非纯黑） |
| `--ink-2` | `#6B675E` | 次要文字（淡墨） |
| `--ink-3` | `#A8A296` | 辅助文字/占位（枯墨） |
| `--line` | `#E8E2D6` | 分割线/描边（绢色线） |
| `--indigo` | `#2F4154` | **主色**：导航/标题强调/主按钮（黛蓝） |
| `--indigo-deep` | `#243342` | 主按钮按压态 |
| `--cinnabar` | `#B03A2E` | **点睛色**：印章/进度/打卡/成就（朱砂，克制使用：单屏≤2 处） |
| `--cinnabar-soft` | `#F5E3DE` | 朱砂浅底（标签底/高亮底） |
| `--night` | `#1E2B38` | 计时页底（墨夜蓝，沉浸场景专用） |
| `--night-ink` | `#F4EFE6` | 计时页前景文字（暖白） |
| `--gold` | `#B8935A` | 评分星/勋章点缀（铜金，低频） |
| 成功/警告/失败 | `#4A7A5E` / `#B8863B` / `#A84234` | Toast/表单反馈（降饱和，融于纸面） |

### 1.2 配色律

1. 纸面层级只做三层：`paper`（底）→ `card`（卡）→ `paper-deep`（卡内分区/按压），不再多嵌套。
2. 朱砂 `--cinnabar` 是仪式色不是功能色：进度、打卡、完成态可用；危险操作用失败色 `#A84234`，不混用。
3. 禁用渐变按钮/渐变底（S1 全站紫渐变是重点替换对象）；唯一例外：计时页夜空可带极轻微纵向明度渐变（`#243342 → #1A2530`）。
4. 文字对比度：`--ink`/`--paper` ≈ 12.9:1，`--ink-2`/`--card` ≈ 5.6:1，`--night-ink`/`--night` ≈ 11.4:1，均过 WCAG AA。

## 2. 字体

| 层级 | 字族（font-family 栈） | 用途 |
|---|---|---|
| 标题/书名/大数字 | `"Songti SC","STSong","Noto Serif SC",serif` | 页面主标题、书名、计时数字、统计大数 |
| 正文/控件 | `"PingFang SC","Helvetica Neue",sans-serif` | 正文、按钮、标签、表单 |

| 字号（rpx） | 行高 | 用途 |
|---|---|---|
| 56 | 1.2 | 计时页大数字（衬线，字重 600） |
| 44 | 1.3 | 页面主标题 |
| 34 | 1.4 | 卡片标题/书名 |
| 28 | 1.6 | 正文 |
| 24 | 1.4 | 辅助说明/标签 |
| 22 | 1.2 | 角标/极小注（下限，不再小） |

数字场景（计时/统计）优先 `font-variant-numeric: tabular-nums` 防跳动。

## 3. 图标与图形语言

- **图标**：统一线性描边（stroke 1.5px、24×24 网格、圆角端点），墨色；选中态黛蓝。库任选其一（uniapp 生态 `uni-icons` 或 SVG sprite），**全面替换 S1 的 emoji 图标**。
- TabBar 四图标语义：首页=书斋灯/卷轴、书库=立册、书架=书堆、我的=印章人。
- **印章元素**（点睛，仅打卡体系使用）：
  - 打卡月历日格：12×12 圆角小方印，朱砂底反白日期数字；
  - 首页目标完成徽记：圆形"阅"字印（盖印动效 0.4s：1.2→1.0 缩放+透明度落定）；
  - 印面带 1px 内描边模拟印泥边缘，不做真实纹理贴图（跨端渲染不可控）。
- 卡片：圆角 12rpx、描边 1px `--line`、无阴影或 `0 2rpx 8rpx rgba(44,42,38,0.04)` 微阴影（二选一全局统一）。
- 按钮：主按钮=黛蓝实底白字、圆角 12rpx、高 88rpx；次按钮=白底黛蓝描边；文字按钮=黛蓝。**废除 50rpx 大胶囊+渐变**。

## 4. 组件风格基线（配合画板「组件样张」区）

| 组件 | 规格 |
|---|---|
| 进度条 | 高 8rpx 圆角，底 `--paper-deep`，填充朱砂；带百分比数字（右对齐 24rpx） |
| Tab（书架三段） | 文字+底部 4rpx 短指示条（黛蓝），角标计数用 `--ink-3` 22rpx；**废除满圆底块 Tab** |
| chips（书库分类） | 高 56rpx 胶囊、选中黛蓝实底白字、未选白底墨字描边 |
| 空态 | 线性插画（书/印主题）+一句文案+一个动作按钮，整体居中，上下留白 ≥160rpx |
| Toast | 沿用系统样式，成功/失败色按 §1.1 |
| 弹层（成果/确认） | 底部半屏抽屉或居中纸笺卡（圆角 24rpx 顶部），不用全屏遮罩模拟 |

## 5. 底座遗留页换肤程度

登录/注册/协议/客服/设置等复用底座页：**仅替换主色变量与标题字族**（低成本换肤），不重排布局；商城类页面去留见 04 篇。

## 6. 计时页专属（夜读场景）

- 底 `--night`，中央暖白衬线大数字（56rpx 以上实际落地为 120rpx 级），书名副行 28rpx `--ink-3` 近似色（夜色下用 `rgba(244,239,230,0.65)`）；
- 控制按钮：夜色下反白描边按钮（描边 `rgba(244,239,230,0.4)`），「结束」为唯一暖白实底按钮（字色 `--night`）；
- 暂停态：数字透明度降至 0.5 + 「已暂停 · 计时后台仍在进行」提示行（对齐 S3 后端墙钟计时口径）。
